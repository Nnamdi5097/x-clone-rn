## 📌 Project Overview
A feature-complete social media web and mobile application inspired by X (formerly Twitter). Built with React Native, TypeScript, Node.js, and Express, featuring real-time feed updates, user authentication, media uploads, and interactive post engagements.

---

## 🛠️ Tech Stack
* **Frontend / Mobile:** React Native, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express.js, REST APIs
* **Database & Hosting:** MongoDB, Vercel

---

## ✨ Key Features
* 👤 **User Authentication:** Secure user signup, login, and session management.
* 📝 **Post Feed & Interactions:** Create posts, view real-time feed updates, like, and comment.
* 🖼️ **Media Uploads:** Seamless image/avatar uploads and processing.
* 📱 **Cross-Platform:** Built with React Native for responsive web and mobile UI.
